# Receipt photos

Real receipts we use to test the scanner. Each photo gets one row in the table below.

## How to add receipts (on github.com, no coding)

1. Open this folder on GitHub: `fixtures/receipts`.
2. Click **Add file → Upload files** and drag in your photos.
3. Name them `receipt-01.jpg`, `receipt-02.jpg`, … (rename on your phone first if you can).
4. Write a short message, like `test: add 5 canteen receipts`, and click **Commit changes**.
5. Open this `README.md`, click the ✏️ pencil, add one row per photo, then click **Commit changes**.

**Don't upload** receipts that show someone's personal phone number, card number or UPI ID. Cover those parts or skip that receipt.
