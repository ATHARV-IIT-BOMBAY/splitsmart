# App text

Every piece of text a user reads in SplitSmart. The **Now** column is what the app says today. Write a better version in **Your version** only where you can improve it, and leave it empty where it's already good.

**Style:** short, friendly, plain English. Say what happened and what to do next. No "please", no "!", no "successfully".
